# PragyanAI Conversational Assistant

An AI-powered RAG chatbot built using:

- LangChain
- LangGraph Ready Architecture
- FAISS
- HuggingFace Embeddings
- Groq Llama 3.3 70B
- Gradio

## Installation

```bash
git clone <repo_url>
cd PragyanAI-RAG-Assistant
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env`

```text
GROQ_API_KEY=your_key
```

Run

```bash
python app.py
```
